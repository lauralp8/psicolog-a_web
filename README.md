# Web Informativa de Psicología

Proyecto de aprendizaje para construir una aplicación web moderna desde cero.

## Tecnologías

- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Base de datos: PostgreSQL
- Despliegue: Vercel

## Objetivo

Aprender desarrollo web profesional construyendo un proyecto real.
